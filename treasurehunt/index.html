TREASURE COMPASS LITEFF14 宝の地図 判別ツール

地図のスクリーンショットを貼り付けると、一致する地点と座標を表示します。

ここに地図画像をペースト Ctrl+V

ドラッグ&ドロップ / クリックしてファイル選択も可。
Win+Shift+S で地図ウィンドウの絵の部分だけを切り取るのがおすすめ。

使い方: まず「登録」タブで手持ちの地図スクショと座標を登録してデータベースを育ててください。 登録済みの地図なら、次回から貼り付けるだけで即座に座標が出ます。

登録する地図画像をペースト Ctrl+V

ゲーム内の地図ウィンドウをスクリーンショットしたものを使用してください。

グレードエリア座標ハッシュ
GitHub Pages での公開手順: ここでダウンロードした maps.json をこの index.html と同じ場所にコミットすると、 ページ読み込み時に自動でデータベースとして読み込まれます。ブラウザ内の一時保存(localStorage)とは別に、 リポジトリの maps.json が全ユーザー共通のマスターデータになります。
記載されている会社名・製品名・システム名などは、各社の商標、または登録商標です。
