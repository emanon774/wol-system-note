FF14 5 Keyboard Keybind Visualizer

5台のフルキーボードにスキルを配置し、各キーボードごとに Ctrl / Alt / Shift を自由に組み合わせられます。

スキル
追加したい画像をここへドラッグ＆ドロップ

General（Sprint / Limit Break）とZIP内のジョブ別PvEアイコンを収録しています。日本語 / English を切り替えられます。日本語名はXIVAPIからジョブ単位で取得しブラウザに保存します。ジョブフォルダ名は元データの名前をそのまま使用しています。Traits（特性）は一覧から除外しています。

Ctrl / Alt / Shift はクリックでON、もう一度クリックでOFF。修飾なしは3つともOFFです。各キーボードの設定は独立しています。ダウンロードは割り当て一覧のTXTファイルのみです。
